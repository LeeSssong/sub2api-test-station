# T133 账号监控连接测试模型入口与主动探测成功率修复规格

## 状态与批准

- 日期：2026-09-05
- 基线：`main@3c7b6530e4a8a6cf9d861cd1852b05ed37736d39`
- 状态：已批准，可进入实施计划
- 用户批准：用户确认将“连接测试模型”原生选择框放到模型检测结果与自动化勾选项旁，并修复主动探测成功率为 0；要求合并、推送后快速部署主站且不同步验收站。

## 问题证据与当前行为

账号监控卡片已经有统一请求计数和成功率字段，但分组投影仍调用旧 `ListGroupWindowAggregates`。该查询只读业务 `usage_logs`/`ops_error_logs`，会以零成功率覆盖统一聚合已经产生的主动探测请求计数。因此在没有业务流量、只有成功主动探测时，卡片会同时显示正的成功请求数和 `0%`。

统一全局与分组查询目前又只选择 `account_monitor_results.status = 'success'`，失败主动探测没有进入请求分母。这不符合用户确认的“主动探测也是真实请求证据”的口径。

“连接测试模型”配置已经由账号字段 `connection_probe_model`、账号模型列表接口、账号保存接口和模型检测对话框原生选择器支持，但账号卡片主操作区没有直接入口，管理员必须进入弹窗才能修改。

## 目标

1. 在账号卡片模型检测结果、自动检测和历史可读性勾选项旁展示紧凑的原生“连接测试模型”选择框。
2. 选择后立即保存；保存中禁用，失败时恢复原值并沿用现有错误提示机制。
3. 全局与分组聚合使用同一五分钟桶证据合同：桶内有真实请求时只用真实请求，否则只取一个主动探测终态。
4. 主动探测成功计成功，失败计失败，二者都进入请求总数与成功率。
5. 保持探测不参与收入、用户扣费或账号成本。

## 非目标

- 不新增监控事实源、数据库迁移或历史回填。
- 不改变主动探测调度频率、题面、自动模型检测算法或账号调度资格。
- 不删除现有模型检测对话框、历史入口或其中的连接测试模型设置。
- 不改变 Sub 原生业务流水的收入、成本或利润口径。
- 不同步或修改独立验收站。

## 方案比较

### 方案 A：只修前端显示

根据成功数在前端重算成功率。改动小，但会掩盖后端分组投影和失败探测缺失，API 与其他消费者继续得到错误数据，不采用。

### 方案 B：统一后端证据并复用原生选择器能力（采用）

删除分组投影对请求质量字段的旧窗口覆盖，修正统一查询纳入成功和失败探测终态；前端增加共享原生配置的紧凑选择框。该方案修复事实源并保持 API 语义一致，范围最小。

### 方案 C：新建探测统计表和独立设置接口

可完全隔离统计，但重复现有事实源和账号保存能力，增加迁移、同步与一致性风险，不采用。

## 端到端数据与控制流

每个账号、每个自然五分钟桶先聚合真实请求最终结果。如果真实请求数大于零，桶输出真实请求总数、成功数、失败数和成功请求 TTFT；该桶不叠加主动探测。否则从 `account_monitor_results` 中选择一个最新终态探测：`success` 输出 `1/1`，失败终态输出 `0/1`，并仅在成功且 TTFT 有效时提供 TTFT 样本。没有真实请求或探测终态的桶不进入分母。

全局账号卡片与分组账号卡片均消费这一统一输出。分组旧窗口聚合仍可提供它独占的非质量字段，但不得覆盖统一请求数、成功数、失败数、成功率和 TTFT。

前端加载账号可用模型列表，使用账号的 `connection_probe_model` 作为当前值；管理员选择后调用既有保存接口。成功则保留新值并更新本地账号投影；失败则恢复选择前的值。

## 接口与字段契约

- 不新增 API 路由或数据库字段。
- `connection_probe_model` 继续表示连接测试使用的模型；空值继续采用后端现有默认语义。
- `request_count = success_count + error_count`。
- `success_rate = success_count / request_count * 100`；分母为零时保持现有零值/空证据语义。
- 失败探测不得产生 TTFT 成功样本；所有探测不得产生 revenue、cost 或 profit。

## 失败与安全语义

- 模型列表加载失败时选择器保持不可用，不伪造模型选项；现有弹窗仍可打开查看已有状态。
- 保存失败时恢复原值，避免界面与后端配置漂移；不得把凭据或上游响应写入提示。
- 未知探测状态不猜测为成功或失败；仅仓储定义的明确终态参与。
- 数据查询失败继续走现有错误返回，不用零值伪装成功。

## 兼容性与迁移

无 schema、配置或数据迁移。已有账号字段和保存接口向后兼容；现有弹窗、历史数据和业务账务不变。

## 场景化验收矩阵

| 场景 | 预期 |
| --- | --- |
| 空桶只有一次成功探测 | 请求 1、成功 1、失败 0、成功率 100% |
| 空桶只有一次失败探测 | 请求 1、成功 0、失败 1、成功率 0% |
| 同桶存在真实请求和探测 | 只统计真实请求 |
| 同桶存在多个探测记录 | 只取一个最新终态，不重复扩大分母 |
| 分组卡片只有成功探测证据 | 不得显示正成功数但成功率 0% |
| 修改连接测试模型保存成功 | 卡片值立即更新，刷新后保持 |
| 修改连接测试模型保存失败 | 选择器恢复原值并显示错误 |
| 主动探测参与质量统计 | 收入、成本、利润仍不增加 |
