# 账号监控成本折合倍率简化设计

**日期：** 2026-08-08
**状态：** 用户已确认

## 目标

账号监控卡片的成本区只展示「成本折合本站倍率」，回答当前账号使用最新探测模型时，其成本折合到本站模型标准价格口径后相当于多少倍。

## 计算

```text
账号有效倍率
  = Sub2API 原生账号倍率
  或 New API 管理员手工登记倍率
  或本站账号成本换算倍率
  仍不可用时为 0

成本折合本站倍率
  = 账号有效倍率
    × 探测请求经账号模型映射后的上游模型单位价格
    ÷ 本站探测模型单位标准价格
```

文本模型换算使用输入与输出单价的等权合计，避免在没有实际 token 结构时偏向单一计费项。请求模型或上游映射模型无可用价格时，折合倍率不可用，页面显示 `--`，不伪造为 0。只有账号倍率本身缺失时按 0 计算。

## 页面

卡片成本证据区只保留：

```text
成本折合本站倍率  0.05x
```

移除上游原生倍率、倍率来源、当前分组倍率、毛利率、成本状态、成本模型、有效样本、证据时间和账单对账文案。真实账单对账链路保留给独立账务功能，不再参与账号卡片展示。

## 验收

- 模型无映射时，折合倍率等于账号有效倍率。
- 模型映射到不同价格模型时，按价格比例换算。
- 账号倍率缺失时回退本站账号成本换算倍率；两者都缺失时使用 0。
- 价格缺失时返回不可用，页面显示 `--`。
- 页面不再请求 relay-ops cost guard，不再显示样本数或账单状态。
