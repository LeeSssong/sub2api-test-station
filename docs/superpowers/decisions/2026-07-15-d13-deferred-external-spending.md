# 决策 D13：所有外部支出延后执行

## 状态

已接受（2026-07-15）

## 背景

项目需要先完成服务器、域名、上游充值、订阅账号、收款和商户渠道等选型，但现阶段不应因登录、实名、结账或支付而中断整体方案准备。用户将在全部建议和配置汇总完成后，自行复核并购买。

## 决策

1. 本阶段不执行任何真实付款、充值、购买、收款、商户申请或付费账户开通，也不代替用户登录相关账户。
2. AI 继续完成供应商调研、推荐配置、预算、备选顺序、风险和最终购买前核对清单，并将结论写入项目报告。
3. 后续方案可基于推荐资产继续设计、生成本地配置并做离线验证；所有这类依赖均明确标记为“假定配置 / 未购买”。
4. 需要真实服务器、域名、账号、余额、商户或客户付款才能完成的验收项保持未完成，并集中进入最终外部操作清单。
5. A01、A02、A05、A06、A07 以及后续新增的外部支出操作，在用户审阅完整报告前一律不触发，也不作为离线规划和本地准备的当前阻塞。

## 影响

- 可以连续完成部署配置、运行手册、成本模型、采购建议和模拟验证，不再逐个停在结账页。
- 公开价格、库存和条款仍可能变化，最终付款前必须重新核对；当前报告中的价格不等同于订单承诺。
- 本地或模拟测试通过不代表生产已部署。真实域名解析、上游调用、支付回调和订阅账号可用性仍需在资产到位后复验。
- 资产台账必须区分“推荐/假定”“已购买”“已验证”，不得用推荐状态冒充所有权或生产就绪。

## 复核触发条件

- 用户审阅完整报告后，明确要求开始某一项真实购买或付费账户开通。
- 推荐商品价格、配置、库存、地区或条款在最终付款前发生变化。
- 后续选型超过已确认预算，或引入新的长期合约、自动续费、押金、冻结资金或不可退款风险。
