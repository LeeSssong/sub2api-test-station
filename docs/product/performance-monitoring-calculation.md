# 性能监控计算口径

## 第四套：混合性能监控

第四套模式与现有自建 Monitor V2 页面并列，不改变前三套的行为。它将当前分组的主动探测成功事件与真实请求成功事件合并为统一数据源：真实请求继续使用 `actual_cost > 0` 且 `usage_completeness` 不是 `unknown` 的严格成功定义，主动探测成功使用现有探测结果。

数据按 UTC 五分钟半开区间聚合。一个区间内只要任一主动探测或真实请求成功，该区间即算可用；可用性为可用区间数 / 总区间数。性能样本只纳入同时具备 `first_token_ms` 和 `duration_ms` 的成功事件，首字与总耗时都使用这一统一集合计算 P95，并统一显示“基于 N 次真实请求”。

当前窗口没有性能样本时，指标回退到最近的历史成功样本；从未有样本时返回确定性的 0，不展示“暂无数据”类文案。卡片圆环为完整空心圆，85% 及以上为绿色，50% 至 85% 以下为黄色，低于 50% 为红色；中心百分比静态显示，圆环仅做呼吸式亮度/光晕变化，并遵循 reduced-motion 设置。

## 既有页面

现有自建 Monitor V2 页面仍保持原有数据合同、布局和展示口径，`channel_monitor_mode=v1` 的路由行为不变。

第四套文档与既有 `/custom/performance-monitor` 口径说明分开保留；旧页面的完整说明见 `performance-monitoring-calculation-legacy.md`。
