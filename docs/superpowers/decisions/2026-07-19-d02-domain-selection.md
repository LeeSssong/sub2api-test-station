# 决策 D02：内测阶段先使用低成本 `.top` 域名

## 状态

候选已确认；域名信息模板审核中，域名尚未注册（2026-07-19）

## 背景

临时 `sslip.io` 仅用于内部技术验证，不能作为外部内测入口。正式入口需要一个可签发可信 TLS 证书、可配置 `api` 子域且成本可控的域名。用户希望先降低内测阶段固定支出，商业化后再评估品牌升级。

## 当前决策

1. 当前候选为 `xingqiaolab.top`，对外 API 子域规划为 `api.xingqiaolab.top`。
2. 腾讯云公开查询页在 2026-07-19 显示该域名可注册，首年约 CNY 14，旁列续费价约 CNY 32。
3. 不把 `.top` 的低价误认为长期品牌结论：商业化前重新比较 `.com` 或其他注册商，并评估用户信任、品牌保护和续费价格。
4. 购买前必须由用户在结算页确认最终总价、注册年限、续费价、实名认证要求、隐私保护、DNS 托管和自动续费状态；Codex 不加入购物车、不下单、不付款。

## 对比依据

- `xingqiaolab.com`：腾讯云公开页显示首年约 CNY 83、旁列约 CNY 90，并提示新用户 `.com` 首年 0 元但 2 年起注；活动资格尚未在用户账户中验证。
- `xingqiaolab.top`：腾讯云公开页显示首年约 CNY 14、旁列约 CNY 32，无需采用 `.com` 活动的两年起购条件。

## 后续动作

域名信息模板审核通过后，由用户亲自完成注册并提供非敏感归属/订单确认；随后配置 DNS、Caddy 证书和 Sub2API 正式站点 URL。保留临时入口直到正式域名的健康、登录、模型列表、同步和 SSE 验收全部通过。

## 风险

`.top` 的公众信任度和长期品牌认知通常弱于 `.com`，部分安全产品对新注册或低价后缀更敏感；因此它适合内测和快速验证，不预先承诺为最终商业品牌域名。
