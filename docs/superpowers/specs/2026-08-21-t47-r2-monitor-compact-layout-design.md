# T47-R2 Monitor V2 紧凑布局与信息层级优化规格

## 问题证据
当前 `MonitorV2GroupCard` 的标题、状态和指标使用 10–16px 字号，时间线 Tooltip 通过 `min-h-[68px]` 常驻占位；桌面服务信息与时间线虽为同一网格，但视觉基线和垂直密度不一致，导致标题与柱状图高度未对齐、各区域分散。

## 目标
- 放大标题、状态、倍率、TTFT、平均延迟和探测时间，提升首屏可读性。
- 让服务信息列与时间线列共享桌面水平网格，标题中心线与柱状图视觉中心对齐。
- 移除 Tooltip 常驻占位高度，改为时间线根节点下方的悬浮层。
- 将时间范围标签贴近柱状图，收紧卡片内外间距，形成统一服务行。
- 移动端保持服务信息在上、时间线在下，并仅允许时间线内部横向滚动。

## 非目标
- 不改变 Monitor V2 API、数据源、契约版本、窗口、刷新、调度或状态语义。
- 不新增迁移、配置、后端代码或生产数据写入。
- 不改变 `operational`/`unavailable`/`NO DATA` 的颜色和标签映射。

## 方案与选择
1. **仅放大字体**：改动小，但 Tooltip 占位和基线问题仍在。
2. **重做为两列大卡片**：层级强但破坏现有紧凑服务行和移动端行为。
3. **紧凑服务行（选定）**：放大关键文字、统一 grid 基线、Tooltip 绝对定位、时间标签贴轨道；最小范围解决用户反馈并保留 T41/T42/T44 行为。

## 行为与兼容性
- GroupCard 继续消费 `MonitorV2Group`，Timeline 继续消费 `MonitorV2TimelinePoint[]`。
- Tooltip 保留 hover/focus、键盘可达、ARIA 和滚动后边界夹紧。
- 无探测结果仍显示灰色虚线桶和 `NO DATA`；服务不可用显示红色 `DOWN`；可用显示绿色 `UP`。

## 验收矩阵
- 桌面：标题/指标字号达到新层级；左列和右列同一服务行；时间线柱体与标题垂直居中。
- 桌面 Tooltip：显示时不增加卡片布局高度；时间标签紧贴柱体。
- 窄屏：卡片上下堆叠，时间线内部可横向滚动，无页面级横向溢出。
- 状态：已有 UP/DOWN/NO DATA 颜色与文案测试继续通过。
- 验证：直接 Vitest、`pnpm typecheck`、`pnpm build`、`git diff --check`。
