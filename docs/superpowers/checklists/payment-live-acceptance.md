- [ ] 商户后台和管理后台启用 2FA，恢复材料进入密码管理器。

- [ ] PAY01 本地配置中的主体、币种、费率和汇率已更新并通过校验。

- [ ] 只打开一个 Provider 和一个前端可见支付方式。
- [ ] 取消限流、注册限流、邮箱验证和邀请制生效。

## 4. 沙箱或最小额测试

每笔记录脱敏订单号、金额、币种、Provider 事件 ID、Sub2API 订单状态、余额流水 ID 和时间；不记录支付凭据。

- [ ] 下单返回正确金额、币种、二维码或支付页面。
- [ ] 正常支付经过签名验证，订单从 `PENDING` 到 `COMPLETED`。
- [ ] 余额只增加一次，订单、Provider 和余额流水可逐笔对应。
- [ ] 同一回调重复 3 次不重复加款。
- [ ] 第二个成功事件不重复加款。
- [ ] 伪造签名、错误金额、错误币种和错误订单号被拒绝。
- [ ] 延迟和乱序回调不会把已完成订单改回失败。
- [ ] 订单超时前主动查单；已支付但回调延迟的订单可恢复。
- [ ] 退款申请、Provider 退款和余额冲减只执行一次。
- [ ] 退款失败、部分退款和人工补单均保留操作人、原因和引用。

## 5. 对账与故障

- [ ] 连续 3 天对齐 Sub2API 订单、Provider 收款和站内余额。
- [ ] 对账差异为 0；任何差异都有订单级解释和处理记录。
- [ ] 关闭 Provider 后前端不再展示该方式，新订单不再路由到它。
- [ ] 回调暂时不可达后，主动查单和补偿任务能恢复订单。
- [ ] 备份和恢复不会重复执行历史支付事件。
- [ ] 客服能查到订单、退款和余额流水，但不能查看支付秘密。

- [ ] 连续 7 天没有重复入账、越权、重大对账或退款事故。
