# T83 Task 1 报告：主动探测当前桶用量读取

## 完成内容

- 新增 `currentActiveProbeBucket`：固定使用 `Asia/Shanghai`，按 5 分钟自然桶返回半开区间 `[start, end)`。
- 新增 `activeProbeBucketKey`，用于后续调度路径稳定标识当前桶。
- 新增窄接口 `ActiveProbeUsageWindowReader`，仅暴露账号/分组当前时间窗是否存在真实用量。
- `usageLogRepository` 新增账号和分组 `SELECT EXISTS` 查询，约束为 `created_at >= from AND created_at < until`，并对 ID 与时间窗做参数校验。
- `AccountUsageService` 通过可选窄接口转发查询；底层 repository 不支持该能力时 fail closed 返回错误，自动探测调用方应跳过上游请求。
- 新增 sqlmock 测试覆盖账号/分组查询参数与存在性结果。
