# 充值页与支付配置修复执行计划

1. 为前端加载失败、重试、布局基准和快捷金额编写失败测试。
2. 为后端可见支付方式 enabled 的关闭、启用、缺失兼容和订单路由编写失败测试。
3. 实现前端 checkout 状态拆分、Figma 结构移植、账户权益和金额档位。
4. 实现后端 visible-method enabled 契约。
5. 运行前端单测、类型检查、构建及后端相关测试。
6. 用浏览器检查桌面和移动端页面，且不发起真实支付。
7. 提交功能分支，合入并推送根 `main`。
8. 通过测试站发布控制器部署，更新支付宝可见方式配置并验证 health、ready、checkout 和页面。
