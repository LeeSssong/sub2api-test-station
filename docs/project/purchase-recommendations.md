## 已准备的默认建议

### DOM01：域名与 DNS

- 首选：复用用户已有域名，增加独立 `api` 子域；采购成本为 0，首版 DNS 直连 Caddy。
- 内测阶段低成本候选：腾讯云 `xingqiaolab.top`，2026-07-19 公开查询显示首年约 CNY 14、旁列续费约 CNY 32；API 子域为 `api.xingqiaolab.top`。
- 商业化升级候选：Cloudflare Registrar `.com` 或腾讯云新客 `.com` 活动；必须在用户账户和最终结算页重新核对资格、两年起购、续费和付款可用性。
- `.top` 适合内测快速验证，不预先承诺为最终商业品牌域名；不建议为更低首年价改用续费明显更高的冷门后缀。
- DNS：使用 Cloudflare DNS，`api` 记录首版设为 DNS only，TTL 300 秒；真实 SSE 和回源验证后再决定是否启用代理。
- 账户：注册商账户启用 2FA，自动续费状态在最终购买前明确确认。
- 状态：`xingqiaolab.top` 已由用户确认作为内测候选；未购买、未改 DNS，仍需用户亲自在结算页完成最终核对和付款。

### UP01：现有上游与首次充值

- 首选：先使用已有上游 API，不因寻找新合作方延误闭环。
- 首次充值建议：`max(平台最低充值额, 7 天测试预计成本)`，单家默认不超过 CNY 100；超过上限时先比较模型倍率、退款规则和其他候选。
- 在充值前必须取得：Base URL、鉴权方式、支持模型、计价币种/倍率、余额查询、RPM/TPM、429 规则、最小充值和退款规则。
- 状态：已知上游存在，但非敏感参数尚未盘点；未建议追加充值，未执行充值。

### ACC01：K12、Plus、Pro 等订阅账号样本

- 首个样本推荐：独立可控的 OpenAI ChatGPT Plus，数量 1，理想价格不超过 CNY 200，硬预算不超过 CNY 300，剩余有效期至少 30 天优先，售后至少 14 天优先。
- 交付要求：买方独立控制主邮箱、恢复方式、密码和 2FA；卖家不保留管理员或恢复权；只走 Sub2API 管理后台正常 OpenAI OAuth。
- Sub2API 假定配置：`platform: openai`、`type: oauth`、独立测试分组 `acc01-openai-plus-test`、并发 1、到期自动暂停；通过 24 小时验收前不进入售卖分组。
- `K12` 只视为卖家标签；学校/组织托管、管理员保留控制权的候选硬淘汰。共享 Pro、Token/Cookie-only、要求凭据提取或绕过登录/验证码/地区风控的候选硬淘汰。
- Pro 和其他平台放在 Plus 首样通过以后比较，不同时采购多个品类，不批量囤货。
- 当前没有指定具体卡网或卖家；公开赞助或营销描述不等于卖家已验收。最终购买前用真实商品资料运行候选评分。
- 状态：首样品类和配置推荐已定；卖家未选，未购买，未登录，未授权。详细配置见 `docs/project/subscription-account-procurement.md`。

### PAY01：收款与商户渠道

- 当前 MVP：只使用人工账本和合成订单，Sub2API 支付开关关闭、可见方式为空，不接收真实客户款项。
- 中国大陆合格经营主体 + CNY 客户：首个正式渠道选择支付宝直连；真实闭环稳定后再增加微信支付直连。
- 海外合格经营主体 + 国际客户：Stripe 作为首选，替代大陆首发路径。
- EasyPay 只作为官方渠道不适用时的回退；资金流、结算、冻结/退款、对账和连续性五项尽调全部通过前不推荐、不启用。
- 假定参数：单笔 CNY 20-200、单用户每日 CNY 200、待支付订单 2、超时 15 分钟、取消限流每小时 3 次、邀请制。
- 状态：条件式推荐、禁用态配置、配置校验和合成回调/退款幂等模拟已完成；经营主体未确认，商户未申请，未配置真实密钥，未收款。详见 `docs/project/payment-channel-selection.md`。

### LINE01：优化线路与第二节点

- 当前推荐：不采购。MVP 保持普通境外线路、单节点和 Sub2API 原生调度。
- 优化线路触发：真实三网数据每个网格至少 20 个样本，证明 `client_to_entry` 是主要瓶颈，并且入口 P95 延迟超过 220 ms 或丢包超过 2%。
- 候选方向：只按受影响运营商比较 CN2 GIA/CTGNet、CMI/CMIN2 或联通优化线路；必须先用测试 IP 重跑同一晚高峰网格，再核对流量包、DDoS、超额费和月成本。
- 第二节点触发：先升到 4 GiB；之后入口自身 7 日可用率低于 99.5% 或持续 SSE 并发至少 30，且预计月故障损失至少为新增节点月成本的 1.5 倍。
- 状态：ROUTE01 评分、熔断、安全重试、网络模板和扩容阈值已完成离线验证；没有真实样本，D10/D11 未触发，未购买。

### BKP01：备份存储

- 首选：PostgreSQL 每日执行 `pg_dump -Fc`，由 restic 客户端加密后写入 Cloudflare R2 Standard；本地保留 7 天，异地保留 30 天，每月在独立临时数据库做一次恢复演练。
- 预算：R2 Standard 当前免费层为每月 10 GB-month、100 万次 Class A、1000 万次 Class B，直接出网免费；超出免费层后存储为 USD 0.015/GB-month，操作请求另计。价格以最终开户页为准。
- 回退：R2 账户或结算不可用时选择 Backblaze B2 S3 兼容存储，并在开户前重新核对存储、请求和下载费用。
- 安全：restic 仓库密码和最小权限 S3 凭据只进入密码管理器或受限秘密文件；普通备份不得包含明文 `infra/.env`、SSH 私钥、上游/支付密钥。
- 状态：推荐、保留期和真实验收清单已完成；未开户、未建 Bucket、未初始化仓库、未执行备份或恢复。

## 状态解释

- `推荐已定`：AI 已完成当前信息下的选型，不代表已经下单。
- `假定配置`：后续配置和文档以该规格为前提，可继续离线准备。
- `已购买`：只能在用户实际完成交易并提供非敏感订单信息后登记。
- `已验证`：必须在真实资产上完成对应检查后登记。
