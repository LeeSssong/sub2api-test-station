# T94 CodexRadar 外部 API 宽容透传设计

## 目标

CodexRadar 固定公开接口返回 HTTP 2xx 且 JSON 可解析时，本站按外部返回内容生成现有社区矩阵，不再因为本站对第三方 schema、空样本、零样本点、重复模型档位或无共同模型/effort 的业务校验而显示“该来源暂时不可用”。

## 边界

- 继续只读固定的 CodexRadar 软件工程与视觉空间公开接口。
- 不读取本站数据库、Redis、账号、分组、Monitor V4、用量或计费数据。
- 保留网络失败、非 2xx、响应超过既有安全上限、非法 JSON 和双源真实失败的错误/最近成功快照语义。
- 综合 tab 没有共同档位时返回 fresh 空数组，由页面展示空态；不伪造共同结果。
- 不改变站长推荐接口、社区计算公式、缓存时长、路由或页面布局。

## 验收

1. 第三方 2xx JSON 即使 schema 版本变化、包含零样本点或重复模型档位，也不会被后端标记为来源失败。
2. fresh 空 tab 与零样本点通过前端合同解析，不触发整块“社区测试数据暂时不可用”。
3. 单源真实请求失败仍只隔离该来源；双源失败且无快照仍返回不可用。
4. 后端定向测试、前端 DTO/组件测试与 `git diff --check` 通过。
