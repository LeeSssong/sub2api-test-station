星桥AI 小白使用教程

从充值、创建 API 密钥到接入 CC Switch 和检查账单，用这一页完成首次调用。控制台入口：https://api.xingqiaolab.top/。

开始前先了解

星桥AI 通过 API 密钥识别调用。请先完成小额充值并创建一个独立密钥，再开始测试；可用模型、分组、价格与倍率以控制台当前展示为准。

首次使用建议：先用低频、小请求验证连通性。不要把密钥贴到聊天记录、截图、公开仓库或前端网页中。

一、充值并确认余额

在控制台打开 充值/订阅，按页面流程完成充值。回到控制台刷新后确认余额变化；如果订单完成后余额仍未更新，请保留订单号并联系支持。

  1. 进入充值页面，选择适合的金额。
  2. 支付完成后回到控制台刷新余额。
  3. 用一笔小测试请求确认扣费记录正常出现。

二、创建 API 密钥

前往 API 密钥 页面，点击创建。为不同项目使用不同名称，便于后续停用、统计和排查。

创建密钥：填写名称并按项目需要设置限制。

创建时可按控制台提供的选项选择调用分组、设置自定义密钥、IP 限制、额度、速率或有效期。限制项没有统一推荐值：测试阶段应保持可控，生产项目应按实际来源和预算收紧。

选择可用调用分组。

创建完成后请立即复制密钥并妥善保存。密钥完整内容通常只在创建时显示；遗失时请新建密钥并停用旧密钥。

在密钥列表中查看、编辑或停用密钥。

三、导入 CC Switch

在密钥详情或列表中使用控制台提供的“使用密钥”或导入能力，将星桥配置带入 CC Switch。导入后检查 Base URL 是否为 https://api.xingqiaolab.top/，并确认选择的是刚创建的密钥。

CC Switch 中启用星桥配置后的状态。

一键导入没有反应怎么办

先确认浏览器允许打开 CC Switch 的协议链接或扩展调用。仍没有反应时，复制控制台显示的连接信息，按下方手动方式填写；不要从不明网页下载配置文件。

手动配置位置

在 CC Switch 的供应商或 API 配置页填写 Base URL、API Key 与可用模型。保存后回到配置列表，确保星桥条目处于启用状态。

四、启动 Codex 并完成首次测试

选择已启用的星桥配置后，启动 Codex 并发起一个简短任务，例如让它解释一段文本。首次测试的目标是确认认证、模型选择和首字返回都正常。

提示：出现错误时不要反复高并发重试。先检查密钥状态、余额、模型和配置地址，再根据错误信息逐项处理。

五、查看 Token 和扣费

前往 用量记录 查看请求时间、模型、Token 与费用明细。输入、输出、缓存 Token 可能采用不同倍率，最终扣费以该页面记录和控制台实时规则为准。

使用记录可用于核对调用量和最终扣费。

建议为每个环境使用单独的密钥。出现异常消耗时，先停用对应密钥，再从用量记录定位请求来源。

六、常见报错

401、Unauthorized 或 invalid_api_key

通常表示密钥无效、复制不完整、已停用或请求未正确携带认证信息。重新复制密钥，确认当前配置使用的是对应项目的有效密钥。

余额不足或无法继续调用

刷新控制台余额并检查 用量记录。余额确实不足时，前往 充值/订阅 完成充值后再测试。

429、请求过多或并发已满

降低并发和重试频率，给失败请求加入退避等待；同时检查密钥的速率限制及当前分组可用状态。

模型不可用或 model not supported

在控制台确认该分组支持目标模型，并检查 CC Switch 中填写的模型名称。不要猜测模型标识，以当前控制台展示为准。

超时、长时间没有首字

先用短提示词和较小输出测试，再检查网络、并发和模型状态。长上下文或高峰时段可能需要更长等待时间。

七、密钥安全建议

  • 每个项目、环境和人员使用独立密钥。
  • 只在服务端环境变量或受管密钥库中保存密钥。
  • 设置必要的 IP、额度、速率与有效期限制。
  • 怀疑泄露时立即停用该密钥并新建替代密钥。
  • 定期查看 用量记录，关注异常调用。

八、完成检查与联系客服

  • 余额已确认，且小额测试已成功。
  • 已创建独立 API 密钥并安全保存。
  • CC Switch 中的星桥配置已启用。
  • 已在用量记录中确认 Token 和扣费。
