# 星桥首页日夜主题与分层信号流设计

日期：2026-07-29  
状态：已获用户确认，待实施

## 目标

提升星桥首页代码流背景的清晰度、纵深和动态质感，同时补全可用的白天/黑夜主题系统。主题默认固定按北京时间自动切换，并允许用户在当前时段内临时手动覆盖。

本次仅改造首页。控制台、文档、`/support` 等其他页面不在范围内。

## 视觉方向

整体继续保持星桥“安静、精确、可信”的产品气质，保留现有青蓝品牌信号色，不照搬竞品的满屏随机字符密度。

### 分层信号流

- 在现有单个 Canvas 内绘制远、中、近三层字符流，不增加 Canvas 数量或 WebGL 依赖。
- 三层使用不同字号、透明度、速度和起始位置，形成明确但克制的空间纵深。
- 大部分字符保持冷灰色，仅让少量活跃信号行周期性增强为青蓝色，并带有限的柔和辉光。
- 标题、正文和主要操作附近保留对比安全区；右上、中央空白区和页面边缘适度提亮。
- 指针移动只轻微改变附近代码流速度和亮度，不加入跟随光圈、粒子爆发或夸张三维效果。
- 首屏和现有 Statement 区域复用同一信号语言，但允许通过参数控制密度与强度。
- `prefers-reduced-motion: reduce` 时停止流动，保留清晰的分层静态背景。

### 主题色彩

白天模式不是深色模式的机械反色，而是独立定义完整层级：

- 白天模式：冷白背景、浅灰蓝代码、深灰正文、蓝青活跃信号。
- 黑夜模式：近黑蓝背景、冷灰代码、白色正文、青蓝活跃信号。
- 导航、首屏、后续内容区、按钮、边框、网格和页脚统一响应主题。
- 保留现有品牌青蓝色，不增加无关装饰色。
- 正文、按钮和交互状态满足 WCAG 2.1 AA 对比度要求。

## 主题行为

### 自动规则

固定使用北京时间（Asia/Shanghai，UTC+8）：

- 06:00:00–18:59:59：白天模式。
- 19:00:00–次日 05:59:59：黑夜模式。

首次打开首页时立即判断当前主题。页面持续打开时，在下一个 06:00 或 19:00 边界自动切换。浏览器标签重新可见、窗口重新获得焦点或设备休眠后唤醒时重新校准，避免错过切换边界。

### 手动覆盖

- 导航栏按钮可立即切换当前主题。
- 手动选择写入本地存储，刷新后在当前时段内继续有效。
- 覆盖记录包含明确的到期边界。
- 到达下一个北京时间 06:00 或 19:00 时，手动覆盖自动失效并恢复时间规则。
- 按钮图标表达点击后将切换到的目标主题。
- 按钮的 `aria-label` 和 `title` 使用对应的中文操作描述，例如“切换到白天模式”。

## 技术设计

### 主题领域模块

新增独立、无 React 依赖的纯函数模块，负责：

- 根据任意时间计算北京时间所处主题。
- 计算下一个 06:00 或 19:00 边界。
- 创建、读取和验证带到期时间的手动覆盖记录。
- 对损坏、缺失或过期的本地存储数据安全降级。

### 主题 Hook

新增首页主题 Hook，负责：

- 初始化主题状态。
- 应用和清理手动覆盖。
- 安排下一个边界定时器。
- 在 `visibilitychange`、`focus` 等事件后重新校准。
- 清理定时器和事件监听器。

### 首屏防闪烁

在 React 首次渲染前同步确定主题，并将 `data-theme="light|dark"` 写到 `<html>`。CSS 以该属性为唯一主题来源，避免首次加载出现先黑后白或先白后黑。

同时更新页面的 `color-scheme` 和 `<meta name="theme-color">`，让浏览器原生控件及移动端浏览器顶栏与当前主题一致。

### CSS 主题层

- 将首页中写死的深色背景、文字、边框、表面和遮罩颜色整理为语义化变量。
- 在 `html[data-theme="dark"]` 与 `html[data-theme="light"]` 下定义两套变量。
- 仅对确实需要独立视觉处理的场景保留少量主题选择器。
- `/support` 保持当前独立主题行为，不被首页主题状态覆盖。

### Canvas 信号层

扩展现有 `HeroSignalCanvas` 数据模型，使每行拥有层级、字号、速度、基础透明度、活跃状态和主题色角色。

仍使用单次 `requestAnimationFrame` 绘制循环，并保持：

- 设备像素比上限。
- IntersectionObserver 的离屏暂停。
- 组件卸载时完整清理。
- reduced-motion 静态回退。
- 窗口尺寸变化时重新布局。

Canvas 从 `<html data-theme>` 获取当前主题，并在主题变化时立即重绘，不重新创建不必要的动画资源。

## 关键状态

- 白天自动主题。
- 黑夜自动主题。
- 当前白天时段中的手动黑夜覆盖。
- 当前黑夜时段中的手动白天覆盖。
- 手动覆盖到期并恢复自动主题。
- 页面刷新后恢复仍有效的手动覆盖。
- 本地存储不可用、内容损坏或记录过期。
- 页面跨越切换边界但定时器被浏览器延迟。
- reduced-motion 静态信号背景。
- Canvas 不可用时的语义静态后备文本。

## 测试与验收

### 自动测试

- 覆盖北京时间 05:59、06:00、18:59、19:00 四个边界。
- 覆盖跨午夜、跨日期和下一边界计算。
- 验证手动覆盖刷新后保留，并在下一边界失效。
- 验证损坏或过期存储记录不会阻止页面启动。
- 验证主题按钮的点击、图标和无障碍标签。
- 验证标签页恢复可见和窗口重新聚焦后重新校准。
- 验证 reduced-motion 下 Canvas 不启动动画循环。
- 保留并更新现有首页、导航和信号背景契约测试。

### 视觉验收

- 深色和白天模式分别检查桌面、平板与移动端。
- 流动代码第一眼可感知，但标题和主按钮仍是最高视觉层级。
- 白天模式不是漂白的深色页面，后续内容区具有完整且一致的层次。
- 切换主题没有明显闪烁、布局跳动或动画重启卡顿。
- 正文、导航、按钮及焦点状态达到 WCAG 2.1 AA。

### 性能验收

- 不新增 WebGL 或重型依赖。
- 不增加 Canvas 数量。
- 离屏时停止动画。
- 在常见桌面和移动设备上保持流畅滚动与主题切换。

## 非目标

- 不修改控制台、文档或 `/support` 的主题体系。
- 不照搬竞品字符内容或构图。
- 不加入粒子爆发、三维摄像机、跟随光圈等高干扰效果。
- 不改动首页文案、信息架构或业务链接。
