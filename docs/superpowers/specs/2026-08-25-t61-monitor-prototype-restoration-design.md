# T61 第四套性能监测原型结构还原

## 范围

仅修复第四套 `hybrid_performance` 页面与已确认原型的结构差异。页面继续复用第四套 `/monitor-v4` 数据合同和现有 `CodexRadarRecommendations`，不改主动探测、真实请求、五分钟可用性、P95 或配置语义。

## 设计合同

- 页面外壳与现有 Monitor V2 一致：统一最大宽度、标题/更新时间、时间窗切换和响应式间距。
- 顶部只替换“分组状态”区域，每个分组为独立等高卡片；三张卡在桌面自动等宽排列，窄屏单列。
- 卡片顶部左侧显示分组名、平台和“持续监控”，右侧固定显示 `倍率：{value}x`。
- 圆环为闭合空心环，中心百分比静止；仅外圈亮度/光晕呼吸，尊重 reduced-motion。
- 首字 P95、总耗时 P95 为等宽双列；底部只展示一次统一样本数，并在下一行显示最近探测时间。
- `CodexRadarRecommendations` 及社区矩阵保持原组件、数据源、失败/加载语义和顺序，不删除、不重做。

## 验收

- 直接相关 Vitest 覆盖页面骨架、推荐区、倍率位置、样本/探测时间、85/50 阈值、静止百分比和无旋转类。
- `pnpm typecheck`、`pnpm build`、`git diff --check` 通过；发布预检以宿主结果为准，预期 `downtime_required=false`。
