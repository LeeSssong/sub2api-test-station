# Sub2API 联系客服入口设计

**日期：** 2026-07-24  
**上游基线：** `Wei-Shaw/sub2api` `v0.1.164`（提交 `cd8bb98c44303b2c8f04c0da340447c992f0cb7d`，标签对象 `38a46fd33795c8946a1e88d0f72597c79ca02a76`）

## 目标

在登录后的 Sub2API 顶部栏增加“联系客服”入口。用户点击后看到 QQ 群二维码与群号 `1080152144`，并可一键复制群号。

## 当前约束

- 当前仓库通过 `infra/compose.yaml` 运行官方预构建镜像，未包含官方 Sub2API 源码。
- Sub2API 将 Vue 前端编译产物嵌入 Go 二进制，不能通过修改现有 `homepage` 实现管理控制台功能。
- 现有 PostgreSQL、Redis 和 Docker 数据卷必须保持不变。
- 当前工作区包含其他未提交改动，本功能不得覆盖或回退它们。

## 方案

将官方 `v0.1.164` 的固定源码快照引入仓库，保留上游提交标识，并基于官方 Dockerfile 构建自定义 Sub2API 镜像。定制代码直接落在官方 Vue 组件体系中，Compose 仅把 `sub2api` 服务从固定官方镜像切换为本地构建的固定名称镜像。

不采用 Caddy HTML/JavaScript 注入。该方式依赖编译产物文件名和页面结构，无法可靠复用 Vue 状态、键盘交互与测试体系。

## 界面与交互

- 在 `AppHeader.vue` 的公告与文档区域加入带客服图标的“联系客服”按钮。
- 桌面端显示图标和文字；窄屏至少保留可识别图标与无障碍名称。
- 点击按钮打开深色/浅色主题兼容的模态框。
- 模态框展示用户提供的 QQ 群二维码、群号 `1080152144` 和“复制群号”按钮。
- 复制成功后短暂显示“已复制”；失败时显示明确失败状态。
- 支持关闭按钮、点击遮罩关闭、`Esc` 关闭，并在打开时将焦点置于弹窗内。
- 二维码作为本地静态资源参与前端构建，不依赖外部图片地址。

## 组件边界

- 新增独立的 `ContactSupportDialog.vue`，负责弹窗呈现、关闭事件和复制状态。
- `AppHeader.vue` 只负责入口按钮与弹窗开关，不承载弹窗内部细节。
- 群号作为组件内固定展示配置，避免为单一常量增加后端配置和数据库迁移。
- 中文和英文界面文字进入现有 i18n 文件；群号和二维码保持一致。

## 构建与部署

- 自定义镜像沿用官方多阶段构建流程，后端版本和数据库迁移基线保持 `v0.1.164`。
- `infra/compose.yaml` 改为从引入的源码目录构建，并使用明确的本地镜像标签。
- 不修改 PostgreSQL、Redis、`sub2api_data` 或其他现有卷定义。
- 上线时只重建并替换 `sub2api` 容器；现有持久化数据继续挂载。

## 测试与验收

- 组件测试覆盖：打开弹窗、显示二维码和群号、复制成功、复制失败、关闭按钮与 `Esc` 关闭。
- 运行上游前端相关测试、类型检查与生产构建。
- 构建自定义 Docker 镜像，确认 Go 后端成功嵌入新前端。
- 使用桌面和移动端浏览器截图验证顶部入口、弹窗尺寸、二维码清晰度和无重叠。
- 验收不需要写入或暴露任何生产凭据。

## 非目标

- 不改动官网 `homepage` 的顶部导航。
- 不新增在线客服、工单系统或 QQ API 集成。
- 不升级到 `v0.1.164` 之外的上游版本。
- 不改动现有业务数据、账号、渠道或计费配置。
