# Sub2API 外置定制迁移：生产前验证报告

日期：2026-08-09
范围：官方核心、星桥控制面、管理员体验合同、官方升级门禁

## 已完成

- 定制能力清单、管理员体验合同和运行时基线已冻结。
- 版本化事件/命令合同、核心事务 Outbox、幂等消费、死信、水位和可重建读模型已实现并通过聚焦测试。
- 同域控制面 API、管理员权限隔离、刷新幂等、余额/账单/倍率快照和请求/健康事件已实现并通过测试。
- 官方 Release 状态机、候选资格、迁移分类门禁、蓝绿提升/回退脚本和 systemd 资格调度已实现。
- 前端保留原管理员 URL、登录、2FA、筛选、排序、分页、刷新和 CSV 语义，并增加新鲜度/降级状态。

后端、relay-ops、updater 的 Go 测试和 `go vet`，前端定向 Vitest、类型检查和构建，以及新增 shell 的 `bash -n` 均通过。`shellcheck` 未安装，未将其结果冒充通过；上线前应在宿主补跑。
