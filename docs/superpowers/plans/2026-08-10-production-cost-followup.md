## Goal

Close the remaining production cost gap without presenting configured or calculated account cost as exact upstream debit.

## Context

- Production is healthy on `main@9e24bfde27a9e1a4751d3a30158e24067b900670`, version `0.1.173`.
- New API token logs use `request_id` generated by the immediate New API relay and expose that identity as `X-Oneapi-Request-Id`; the current OpenAI gateway persists only `x-request-id`, which can be the relay's downstream provider ID and therefore cannot match `/api/log/token`.
