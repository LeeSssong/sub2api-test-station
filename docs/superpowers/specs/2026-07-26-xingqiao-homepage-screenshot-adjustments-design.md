# 星桥首页截图整改设计

## 目标

按四张标注截图调整 `homepage`，增强首屏对角线构图与请求链路的指标关联，修正价格文案，并让兼容接入示例复用星桥现有 `baseUrl`。

## 范围

仅修改以下首页模块及其必要的测试、样式：

- `HeroSection`：首屏构图
- `RequestJourney`：实时链路与观测指标关联
- `ValueSections`：价格倍率文案
- `IntegrationSection`：接入标签与动态基础地址

不重做页面信息架构，不改变请求旅程的阶段算法，不修改后台接口。

## 设计

### 首屏构图

桌面端将主标题、副标题和操作区整体上提，在保留现有两列布局的基础上，让左侧标题块与右侧模型接入说明形成从左下向右上的对角线。右侧说明保持可读，首屏底部仍保留向下探索入口。

平板与移动端继续使用单列布局，不强制制造对角线，避免标题、按钮和导航发生拥挤或重叠。

### 实时链路

保留现有自动播放周期、阶段切换与数值增长逻辑。通过以下视觉调整加强链路与右上角“延迟”“Token”的关联：

- 提高两段轨道的基础亮度与激活态对比度
- 增强移动光标的尺寸、中心高光与外发光
- 在观测阶段强化通往模型通道的轨道和指标区域
- 使用克制的同色系高亮，不增加新的说明文案

静态及减少动态效果模式继续显示完整链路，不依赖动画传达信息。

### 价格文案

显示与无障碍文本统一为：

`官方价格的 0.1—0.3 倍`

使用单个中文连接号，修正原有破折号和中文句点错误。

### 兼容接入

移除 OpenAI、Anthropic 标签左侧的花括号图标，保留供应商名称和方向箭头。

基础地址不再显示占位文案。`IntegrationSection` 接收现有 `SiteConfig`，两行共同使用 `config.apiOrigin` 作为星桥 `baseUrl`：

- `OPENAI_BASE_URL=<星桥 apiOrigin>`
- `ANTHROPIC_BASE_URL=<星桥 apiOrigin>`

`apiOrigin` 已由现有配置加载逻辑校验，并在未显式配置时回退到当前站点源，因此无需硬编码生产域名。OpenAI 与 Anthropic 的原生接口路径继续分别显示为 `/v1/chat/completions` 和 `/v1/messages`。

## 验证

- 更新组件测试，覆盖倍率文案、图标移除和动态 `apiOrigin`
- 运行首页单元测试、TypeScript 类型检查和生产构建
- 在桌面与移动视口检查首屏、请求链路和兼容接入区域
- 检查减少动态效果模式，确保关键链路和指标仍清晰可见
- 检查页面无文本溢出、遮挡或横向滚动

## 非目标

- 不新增模型供应商
- 不改变实时链路指标的模拟数值
- 不修改星桥网关或 SDK 的实际协议行为
- 不硬编码星桥生产域名
