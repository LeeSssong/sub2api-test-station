# Narra 测试站工作站接入

用户已批准本方案并授权实施、推送测试站 main 和部署；2026-10-10 最终授权本次测试站停机部署。主站 origin/main 只读，根目录 main 不修改；测试站分支以获取的 origin/main 为合并基线，最终仅推送 test-station/main。

保留 Narra Next 创作台、PostgreSQL 任务队列和 Go Worker。取消独立登录/注册/登出、积分/退款、自填渠道、公开广场和长期会话。本站用户 JWT 经本站 profile 验证，身份映射为不含密码的影子记录；管理员复用本站角色。只允许固定测试站网关；用户 Key 入口校验后以加密快照供 Worker 调用本站同步 Images API，原计费代码不修改。

每次打开产生随机创作会话，6 小时有效，不恢复旧会话。图片及参考图保存在服务器专用目录，受会话/本站管理员权限控制；后台显示所有尚未清理图片。到期清理每分钟运行，任务结束清除 Key，管理员任务元数据最多 24 小时。安全重试仅提交前错误；提交结果不明不重试。存储通过独立适配接口，后续可换 S3 不改调用者。

独立工作站数据库和文件目录与本站账务数据库隔离。新增服务先就绪再挂载路由，本站 API 更新复用既有执行器；本次同步包含迁移，先恢复演练，停止业务写入后备份并迁移，验证后恢复流量。既有 80 个主站提交中数据库迁移先做兼容性预检；不绕过迁移校验。存储设容量限制且留宿主剩余空间下限。保留原 AGPL 许可证、上游 SHA 和可获取源码入口。
